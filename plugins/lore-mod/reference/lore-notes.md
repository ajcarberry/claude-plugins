# EpicGames/lore: repository-specific notes (example config, as of 2026-09-17)

- Repo: `EpicGames/lore`. Releases are tags only (v0.8.3 through v0.9.0; v0.10.0 imminent). No nightly binaries; CI artifacts are docs only.
- Mirror model: community PRs are imported into the internal repo and land as mirrored commits; the PR is closed, labelled `imported` and `merged`, with a bot comment "Closed by mirrored commit <sha>". The commit carries `Imported-PR: #n`. GitHub's `merged` flag stays false.
- Labels (18, CR 375 taxonomy): `needs-triage` (untriaged), `bug`, `enhancement`, `documentation`, `duplicate`, `wontfix`, `good first issue`, `help wanted`, `area:client|server|core|ci`, `LEP`, `imported`, `import-failed`, `ready-to-import`, `tracked`, `merged`; `docker` and `python` slated for removal. No `question` or `invalid` label.
- Governance: any Maintainer may close; Core Maintainers (Mattias Jansson, Raghav Narula) decide technical won't-fix; the Steering Group (Alex Carberry, Garren Gotthardt, Manuel Lang, Mattias, Raghav) decides scope; decisions are public. Questions route to Discord `#support-requests`, feature ideas to `#feature-requests`, community tools to `#show-and-tell` (invite https://discord.gg/E4SFJKRPbg). Discussions disabled. Security via https://hackerone.com/epicgames or security@epicgames.com.
- Binaries: `lore`, `loreserver`; assets `lore-<tag>-<triple>.tar.gz`; v0.8.3's server tarball nests the binary one directory down; `chmod +x` and `xattr -dr com.apple.quarantine` needed on macOS. Zero-config server uses ports 41337 (QUIC and gRPC) and 41339 (HTTP) with its store under `$TMPDIR/lore-server`. `lore repository create --offline <name>` needs no server.
- Build: `cargo build --release -p lore-client --bin lore -p lore-server --bin loreserver` (about 17 minutes cold on an M-series laptop; incremental after). The CLI keeps user state under `~/Library/Application Support/com.epicgames.lore/`.
- Roadmap theme slugs (from `docs/roadmap.md` anchors): `lore-oss-and-uefn-compatibility`, `vs-code-plugin`, `scalable-file-locking`, `virtual-file-system`, `links-and-layers`, `desktop-client`, `unreal-editor-plugin`, `web-client`, `edge-instances-and-advanced-server-topologies`, `forks-and-isolated-partitions`.
- Known docs gaps (Sept 2026): `.loreignore` and view filters documented only in system-design and glossary; `[environment.endpoint] auth_url` absent from the server config reference; no supported gitignore subset documented; no glibc or distro floor in the install docs; no `rust-version`.
