# Launchpad Web Pack

Web domain skills for the launchpad flight sequence. Core browser verification lives
in launchpad itself (`browser-verified-web-work`); this pack adds what's web-specific:

- **web-quality-checks** — perf (Core Web Vitals) and a11y passes for user-facing surfaces
- **web-landing-mechanics** — how `/land` deploys, observes, and validates web projects

Thin by design — grows from real friction, not speculation.
