# Launchpad TPM Pack

Technical product management skills for the launchpad flight sequence — `/mission`
and the flight rules apply to documents as much as code:

- **product-spec-authoring** — PRDs, one-pagers, and decision docs: problem before solution, alternatives on the record, measurable outcomes
- **tpm-landing-mechanics** — how `/land` works when deploy means publish: sign-off checklists, skeptic review, comprehension checks

Thin by design — grows from real friction, not speculation.
